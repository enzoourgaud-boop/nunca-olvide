# À vérifier par le professeur

Ce fichier liste tout ce qui, dans le jeu, **ne vient pas directement de tes documents** (transcrits dans [`sources/contenu-sequence.md`](../sources/contenu-sequence.md)). Pour chaque point : coche ☑ pour valider, ou écris ta correction à côté.

Pour corriger ou retirer une question, tu as trois possibilités :
- dans l'**espace professeur** (onglet Questions), cherche l'identifiant, puis modifie ou désactive la question ;
- dans le fichier `content/sequences/guerra-civil/questions/…json`, corrige la question, ou ajoute `"disabled": true` pour qu'elle ne soit plus posée ;
- ou dis-le-moi, je m'en occupe.
